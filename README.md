# 📊 Chocolate Sales Dashboard (Excel)

This project contains a responsive and interactive Excel dashboard built to analyze chocolate sales data. The dashboard offers rich visual insights into product performance, regional sales trends, and sales team contributions.

---

## 🧾 Dataset Overview
The dataset includes the following columns:

- **Sales Person** – Name of the salesperson
- **Country** – Country where the sale occurred
- **Product** – Type of chocolate sold
- **Date** – Date of sale
- **Amount** – Sale amount (converted to numeric)
- **Boxes Shipped** – Number of boxes delivered

---

## 📈 Dashboard Features

- Pivot charts and tables for:
  - 📍 Sales by Country
  - 👤 Sales by Sales Person
  - 🍫 Sales by Product
  - 📅 Monthly Sales Trends
  - 📦 Boxes Shipped by Region
- 📊 Interactive slicers for filtering by:
  - Country
  - Product
  - Sales Person
- 💡 Clean UI and responsive layout
- 📤 Prepared for full-screen presentation

---

## 🧰 Tools Used

- Microsoft Excel 2014+
- Pivot Tables and Charts
- Slicers for interactivity
- Formula-based data cleaning
